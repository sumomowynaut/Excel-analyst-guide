# Excel 从入门到精通：从会做表到会分析

一份**按分析师工作流组织**的 Excel 教程，中文，单文件自包含，可边读边练。

> 大多数 Excel 教程按**功能**讲：界面、函数、透视表、Power Query……学完你知道每个按钮在哪。
> 这份按**工作流**讲：接需求 → 取数 → 清洗 → 建指标 → **分析** → **可视化** → **汇报**。
> 学完你不只会做表，还知道拿到一个业务问题时从哪下手。

## 三条使用提醒

1. **请用 Excel 桌面版练习**。Power Query、Power Pivot、动态数组、XLOOKUP 在飞书表格和 WPS 中不支持或支持有限，在那里练会以为是自己学错了。
2. 基于 **Excel 2021 / 365 / 2024**。Mac 用户把 `Ctrl` 换成 `Cmd`。
3. 教程里所有参考答案都用公式算过并交叉校验，**不要手算** —— 本文档自己就有一条规则叫"答案必须用公式算"。
